## Key Conclusions

1. **Fillet/chamfer add a new face at an edge location**. Holes/shell do not add new faces.

2. **Fillet/chamfer produce token changes on +X/+Y faces** that have IDENTICAL structural properties (ec/vc/secCount). Holes/shell do NOT produce token changes on unrelated faces.

3. **Multi-loop faces do NOT distinguish the groups**. C09 (chamfer) has 0 multi-loop faces but produces global token changes. C04/C05/C11 (holes) have 2 multi-loop faces but do NOT produce global token changes.

4. **Face count does NOT distinguish the groups**. All models except C10 have 7 faces.

5. **The distinguishing factor is adding a new face at an edge location**. C03/C09 add a new face; C04/C05/C10/C11 do not.
