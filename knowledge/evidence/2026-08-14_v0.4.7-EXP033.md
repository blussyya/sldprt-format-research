## 1. Experiment ID

EXP-033

## 2. Question

Why do C03 (fillet) and C09 (chamfer) produce modified Block1 token signatures for otherwise comparable planar orientations, while C00/C04/C05/C11 retain the standard signatures?

## 3. Hypotheses Tested

| ID | Hypothesis | Test Method | Outcome |
|----|------------|-------------|---------|
| H1 | Token signatures are determined primarily by feature type | Compare signature changes across feature types (fillet, chamfer, hole) | SUPPORTED |
| H2 | Token signatures are determined primarily by local topology | Check if signature changes correlate with structural property changes | FALSIFIED |
| H3 | Token signatures depend on whether a face is directly modified by a feature | Check if signature changes correlate with direct modification | FALSIFIED |
| H4 | Token signatures depend on adjacency to modified geometry | Check if signature changes correlate with adjacency | FALSIFIED |
| H5 | Token signatures depend on global model state/serialization | Check if signature changes correlate with face index changes | SUPPORTED |
| H6 | Token signatures are determined by orientation plus another structural variable | Check if orientation alone explains signature variation | SUPPORTED |

## 5. Analysis

### 5.1 Hypothesis H1: Feature Type

**Prediction**: Different feature types produce different signature changes.
**Evidence**: Fillet and chamfer produce identical signature changes (4 changes each, same patterns).
**Interpretation**: Signature changes are NOT caused by feature type specifically, but by some common property. This falsifies H1.

### 5.2 Hypothesis H2: Local Topology

**Prediction**: Signature changes correlate with structural property changes.
**Evidence**: Signature changes occur while all structural properties (ec, vc, secCount, b1Len) remain identical.
**Interpretation**: Signature changes are NOT caused by local topology. This falsifies H2.

### 5.3 Hypothesis H3: Direct Modification

**Prediction**: Signature changes occur on faces directly modified by the feature.
**Evidence**: Signature changes occur on +X/+Y faces, which are NOT directly modified by the feature.
**Interpretation**: Signature changes are NOT caused by direct modification. This falsifies H3.

### 5.4 Hypothesis H4: Adjacency

**Prediction**: Signature changes occur on faces adjacent to modified geometry.
**Evidence**: Signature changes occur on +X/+Y faces, which are NOT adjacent to modified geometry.
**Interpretation**: Signature changes are NOT caused by adjacency. This falsifies H4.

### 5.5 Hypothesis H5: Global Model State

**Prediction**: Signature changes correlate with face index changes.
**Evidence**: Signature changes occur while face index remains the same.
**Interpretation**: Signature changes are caused by global model state, not face index. This supports H5.

### 5.6 Hypothesis H6: Orientation Plus Structural Variable

**Prediction**: Orientation alone explains signature variation.
**Evidence**: Within C00, orientation alone explains all signature variation.
**Interpretation**: Orientation plus another structural variable determines signatures. This supports H6.

## 6. Conclusions

### 6.1 Primary Conclusions

1. **Fillet and chamfer produce identical signature changes**: Both features produce the same changes for +X and +Y orientations.
2. **Signature changes occur without structural changes**: The +X and +Y faces have identical structural properties but different signatures.
3. **Signature changes occur without direct modification**: The +X/+Y faces are not directly modified by the feature.
4. **Signature changes occur without adjacency**: The +X/+Y faces are not adjacent to modified geometry.
5. **Signature changes occur with same face index**: The +X/+Y faces have the same face index across models.
6. **Hole models do not produce signature changes**: C04/C05/C11 retain standard +X/+Y signatures.

### 6.2 Secondary Conclusions

1. **Signature changes are specific to fillet/chamfer models**: The changes are not caused by feature type specifically, but by some common property.
2. **Signature changes are caused by global model state**: The presence of a feature affects token signatures of unrelated faces.
3. **Orientation plus structural variable determines signatures**: Orientation alone explains some variation, but additional variables are needed.

### 6.3 Negative Conclusions

1. **Signature changes are NOT caused by local topology**: Structural properties do not explain the changes.
2. **Signature changes are NOT caused by direct modification**: The faces are not directly modified.
3. **Signature changes are NOT caused by adjacency**: The faces are not adjacent to modified geometry.
4. **Signature changes are NOT caused by face index changes**: Face index remains the same.

## 7. Recommendations

### 7.1 For Next Experiment

1. **Compare global model state**: Analyze the global model state of C00 vs C03/C09 to identify what property causes signature changes.
2. **Test common property**: Determine what property is common to fillet/chamfer models but absent in hole models.
3. **Predict signature changes**: Test whether this property can be used to predict signature changes.

### 7.2 For Parser Development

1. **Token interpretation**: Parser should not interpret tokens as vertex/edge indices.
2. **Global model state**: Token signatures may encode global model state, not just local face properties.
3. **Feature detection**: Token patterns can be used to detect the presence of fillet/chamfer features.

## 8. Limitations

1. **Sample size**: Limited to 6 models (C00, C03, C04, C05, C09, C11).
2. **Feature types**: Only fillet, chamfer, and hole tested.
3. **Orientations**: Only axis-aligned orientations tested.
