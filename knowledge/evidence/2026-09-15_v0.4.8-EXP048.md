Date produced/captured: 2026-09-15. Source script: [exp048_step_cones.js](../../v0.4.8/exp048_step_cones.js). Exact command from repository root: `node v0.4.8/exp048_step_cones.js`.

Raw output: [EXP048_RESULTS.json](../../v0.4.8/EXP048_RESULTS.json), containing input and dependency SHA-256 hashes, all STEP cone candidates, per-face parameters and errors. Terminal output is the JSON totals object. Inputs are the original USB hub BOTTOM SLDPRT and BOTTOM ORIGINAL.STEP; extracted STEP files were not used. Explicit millimetre/radian units are checked.

All eight tag-4003 face records match independently exported STEP cone axis (up to sign), half-angle and apex within the script's thresholds. Stored slots 0–2 are a reference-axis point, slot 6 the reference radius, slot 7 the half-angle in radians, and slots 3–5 agree with apex = origin + storedAxis * radius/tan(angle). Max apex-equation error: 8.673617379884035e-19 m. Max matched STEP apex error: 1.734723475976807e-18 m.

Seven faces also pass the all-vertex cone-surface residual threshold of 1e-7 m, with maximum residual 1.64778805877841e-9 m among those passes. Face 35 has matching analytic metadata but fails the vertex test at 1.595926441797131e-5 m (about 16 micrometres). This is not evidence that the metadata is wrong; exact surface parameters and approximate display vertices must remain separate. The cause of the discrepancy has not yet been established.

The STEP file contains 16 cone entities; matching faces have multiple candidate entities, so this does not establish one-to-one trimmed-face correspondence. Both cone nappes are allowed by the absolute-radius residual; orientation, trims and exact B-rep reconstruction were not validated. Scope: one independently exported model, eight cone records; not all tag-4003 occurrences or file versions.

EXP-048's bottom model has no scalar-bearing cone face, so it validates the analytic cone interpretation but not the scalar arrays against independent STEP UV coordinates. No parser change or new general invariant was made.
