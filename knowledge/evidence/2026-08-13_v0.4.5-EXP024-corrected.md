## Note on a secondary bug found and fixed during this correction

An initial version of this script's INV-017 check required the Block1 body to end exactly on a `ONE` token (i.e., no trailing partial section), which produced 0 VALID again for a different reason (`INV017_FAIL` on all 1,172 genuine faces). Cross-checking against the already-validated section-splitting algorithm in `v0.4.2a/audit_v042a.js` (lines 484-491: a `ONE` closes the current section if non-empty and starts a new one; **any trailing partial section after the loop is also pushed**) showed the initial version's requirement was wrong. This is disclosed in `v0.4.5/CORRECTION_NOTE.md` for transparency. It does not affect any v0.4.4 evidence and was caught before any results were published.
